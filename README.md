# سالن آرایش — پروژه Next.js + shadcn/ui

طرح اولیه‌ی صفحه اصلی سالن آرایش مردانه، با تم مشکی/طلایی، فونت فارسی وزیرمتن (Vazirmatn) و راست‌به‌چپ کامل.

## راه‌اندازی

```bash
npm install
npm run dev
```

سپس آدرس http://localhost:3000 را باز کنید.

## اضافه کردن کامپوننت‌های بیشتر shadcn

پروژه با `components.json` آماده‌ی CLI رسمی shadcn است. برای افزودن کامپوننت جدید (مثل input یا dialog):

```bash
npx shadcn@latest add input
```

## ساختار

- `app/layout.tsx` — فونت، جهت راست‌به‌چپ، تم تیره
- `app/globals.css` — رنگ‌های تم (پس‌زمینه تیره + طلایی) به‌صورت متغیرهای CSS
- `app/page.tsx` — صفحه اصلی (هدر، هیرو، خدمات، گالری، درباره، تماس، فوتر)
- `components/ui/` — کامپوننت‌های shadcn (button, card)

## نکات برای مرحله بعد

- اسم واقعی سالن، شماره تماس و آدرس را در `app/page.tsx` و `app/layout.tsx` جایگزین کنید.
- تصاویر واقعی گالری را به‌جای باکس‌های placeholder در بخش `#gallery` قرار دهید.
- فرم رزرو نوبت هنوز پیاده‌سازی نشده؛ فعلاً فقط دکمه نمایشی است.
